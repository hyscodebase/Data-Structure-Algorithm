## 기록과 재현

- 각 문서의 코드 블록을 명시된 실행 환경에서 실행한다.
- [manifest.json](manifest.json)은 출처 식별자, UTF-8 파일의 SHA-256, 검증 범위를 기록한다.
- [CHANGELOG.md](CHANGELOG.md)는 이 폴더의 변경을 기록한다.
- 출처 대화 링크는 소유자에게만 열릴 수 있다.

강의자료 원문·시험지·개인 채점 기록·대화 전문을 보관하는 폴더가 아니다. 설명의 정확성과 예제의 재현 가능성을 확인한 자료만 포함한다.
