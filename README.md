# C 자료구조·알고리즘 실습

C로 자료구조와 알고리즘을 학습하는 장별 예제 모음입니다. 각 소스는 독립된 예제 또는 함수 조각이며, 저장소 전체를 하나의 실행 파일로 빌드하는 프로젝트는 아닙니다.

## 학습 구성

| 폴더 | 주요 주제 |
|---|---|
| `chap01/` | 실행 시간 측정과 순차 탐색 |
| `chap02/` | 재귀, 팩토리얼·피보나치·거듭제곱·하노이 |
| `chap03/` | 배열·구조체·포인터·동적 메모리·행렬·다항식 |
| `chap05/` | 큐·원형 큐·덱·은행 시뮬레이션 |
| `chap06/` ~ `chap07/` | 리스트, 연결 리스트, 연결 스택·큐 |
| `chap08/` | 이진 트리·이진 탐색 트리 |
| `chap09/` | 힙·힙 정렬·허프만 코드 |
| `chap10/` 이후 | 그래프와 정렬·탐색 관련 예제 |

[전체 소스](chap01)에서 시작해 장별로 확인하세요. 폴더 안에는 코드 외의 예전 실습 자료도 포함되어 있습니다.

## 한 예제 실행

GCC 또는 Clang이 설치된 터미널에서 저장소 루트 기준으로 실행합니다.

```bash
mkdir -p build
gcc -std=c17 -Wall -Wextra chap01/calc_time.c -o build/calc_time
./build/calc_time
```

다른 파일을 실행할 때는 소스 경로와 출력 이름을 바꿉니다. `main`이 없는 파일에는 별도의 테스트용 진입점이 필요합니다. 동일한 `main`을 가진 여러 예제를 한꺼번에 링크하지 마세요.

## 실습 참고

일부 예제는 Windows 전용 함수나 이전 컴파일러 문법, 과거 인코딩을 사용할 수 있습니다. 컴파일 오류가 나면 해당 파일의 헤더·함수·인코딩을 먼저 확인하세요. 실행 시간 측정 예제의 값은 컴파일 최적화와 실행 환경에 따라 달라집니다.
